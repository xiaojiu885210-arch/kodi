# 抖音 Kodi 插件

在 Kodi 里刷抖音推荐、搜索、热搜。关注和喜欢存在插件里，长按 OK 进作者主页。

插件 ID：`plugin.video.douyin`  
当前版本：`1.3.0`

这是**非官方**插件，仅供个人学习使用。视频版权归抖音和创作者所有。

## 安装（从 zip）

打开 [Releases](https://github.com/xiaojiu885210-arch/kodi/releases)，下载 **plugin.video.douyin-1.3.0.zip**。

不要点 GitHub 绿色「代码」按钮里的 `kodi-main.zip`（会报结构无效）。
也不要在 Actions 页下包。

1. 把 zip 原封不动拷到电视 / 盒子（U 盘最稳）。
2. Kodi → 设置 → 系统 → 插件 → 打开「未知来源」。
3. 插件 → 从 zip 文件安装 → 选 `plugin.video.douyin-1.3.0.zip`。
4. 视频插件 → 抖音。

## 遥控器

- 推荐里点进一条，**播完自动下一条**。
- 全屏播放时用遥控器 **下一首 / CH-** 切下一条。
- **长按 OK** 打开菜单：进入作者主页、关注作者、喜欢此视频。
- 搜索在首页第一排，可搜视频或粘贴分享链接。

关注和喜欢只存在这台 Kodi 上。
